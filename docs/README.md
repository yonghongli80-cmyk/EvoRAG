## 当前维护原则

1. 新工作只从当前代码、测试失败或新的明确需求建立待办。
2. 不根据历史计划中的空复选框重复开发已经存在的功能。
3. 已实现计划保留原文，不批量改写历史过程；在文档顶部标注归档状态。
4. 性能优化和依赖弃用升级单独实施、单独验证，不与业务功能混改。
