## 6. 不可违反的架构红线（所有计划共用）

1. **单平台**：一套 Vue + 一套 FastAPI + 一套身份/权限/消息/审计；助手只是配置，不复制账号/存储。
2. SQLite `document_permissions.current_version_id` 是**唯一当前版本权威**；Qdrant `is_current` 只是可修复元数据。
3. **最终答案缓存保持禁用**（曾有跨用户泄漏，勿重开）。
4. 助手/模型只能**收窄**权限，不能扩权；固定话术路径严禁调用 LLM。
5. 置信度只给 `high/medium/low/unavailable`，**不给百分比**。
6. 真实工资/考勤数据必须主管批准才启用；管理员默认无明文查看权。
7. 物理路径、凭据、向量 ID 永不进 API 响应；`#footer` 具名插槽在无 Element Plus 的测试渲染下不可见（前端组件测试注意）。
8. TDD 纪律：先写失败测试 → 实现 → 跑通 → 提交；测试用临时 SQLite/文件 + fake 后端，**绝不写生产 `data/` 与 `qdrant_data/`**。
