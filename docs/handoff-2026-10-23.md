### 每次推送（两个仓库都要）

```powershell
# 先确认工作树干净、测试通过
git status --short
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider

# 推 main 到两个远端（两边都是 fast-forward 时）
git push origin main
git push github main

# 标签只在新建时推一次；已存在会提示 up-to-date
git push origin --tags
git push github --tags
```

若某一边出现非 fast-forward，**不要强推**；先 `git fetch <remote>`、
确认差异后合并/变基，再推。GitHub 的 443 端口 SSH 配置已生效，
`git ls-remote github` 应能直接返回。
