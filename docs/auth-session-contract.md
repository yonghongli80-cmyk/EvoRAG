# 登录会话处理约定

浏览器通过后端 Cookie 维持登录状态。前端不把访问令牌保存在本地存储中。

| 响应 | 当前会话 | 旧会话的迟到响应 |
| --- | --- | --- |
| `401 Unauthorized`（未登录或登录已失效） | 清除当前用户，标记会话检查已完成，并清空共享的聊天和文件数据。请求仍以原始错误失败。除非当前已经在 `/login`，否则跳转到 `/login`。 | 不修改当前账号、共享数据或路由；原始请求错误仍返回给调用方。 |
| `403 Forbidden`（当前用户无权执行操作） | 清空共享的聊天和文件数据，显示权限不足提示；保留当前用户和路由。 | 不清除新账号的数据，不显示提示，也不触发跳转；原始请求错误仍返回给调用方。 |

普通 Axios 请求和流式请求遵循相同规则。每个请求带有发起时的会话代数；处理重置之前先核对代数，因此旧账号的迟到响应不能影响后来登录的账号。`/me` 探针也使用此保护；当前会话的 `401` 会将探针结果标记为未登录。

取消请求和网络故障不会注销用户。`403` 只清空共享聊天和文件数据；组件自己的局部状态由组件负责处理。
