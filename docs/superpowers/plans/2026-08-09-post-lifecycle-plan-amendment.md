## 不可违反的系统约束

1. SQLite `document_permissions.current_version_id` 是当前版本的唯一权威；Qdrant 的 `is_current` 仅是可修复派生元数据。
2. 先做 ACL 过滤，再做证据计数、冲突检测、置信度和比较；不可见资料的名称、路径、ID 或内容均不得进入模型输入或 API 响应。
3. 最终答案缓存保持禁用。若后续计划引入缓存，必须使用独立、受 ACL 与权限版本失效保护的命名空间，且不得缓存生成答案。
4. 置信度只能是 `high`、`medium`、`low`、`unavailable`，不得输出百分比。无可见当前证据时拒答或澄清，不能生成猜测答案。
5. 历史资料不能提高置信度，必须携带过期警告。销售承诺等时效性场景不得仅凭历史资料作答。
6. 助手与模型只能缩小权限；固定话术路径禁止调用 LLM、embedding 或 reranker。
7. 所有任务采用 TDD：先写失败测试、确认失败、最小实现、通过相关测试，再提交。测试只能使用临时 SQLite、文件和向量集合，不能写生产 `data/` 或 `qdrant_data/`。

## 各计划开工前的必要调整

### 计划 3：回答可靠性

- 保留为下一项工作，但 Task 1 的 `EvidenceRef` 必须容纳既有的 `document_id`、`document_version_id`、当前/历史状态与引用信息；历史证据不得视作当前证据。
- 先做 `llama-index-core>=0.14.23,<0.15` 的隔离兼容性验证和 `pip check`，再把它接入主路径；不以“安装成功”代替兼容结论。
- 在 Task 2 前增加 Task 1.5：分别传播 RRF `retrieval_score` 与真实 `rerank_score`；可靠性阈值只读取后者。reranker 降级时分数为 `None`，不得用排名、常量或归一化 RRF 冒充。
- 企业知识库请求缺少 `user` 或 `user_db` 时在检索前返回 `permission_limited`。仅直接本地文件 CLI 保留为可信兼容模式，FastAPI 不得启用该旁路。
- SQLite ACL 没有选出可见版本 ID 时，版本化检索必须返回空集，不能退回无版本限制检索；外部 reranker 只能看到已按可见版本缩小的 chunk。
- legacy `RAGAgent` 在能返回类型化、逐项可引用证据前默认进入 `clarification_required`，不得绕过可靠性判断或产生无引用答案。
- Task 7 迁移前必须读取当前 `knowledge_tasks` 的实际 DDL 和索引/触发器。不得假定旧的两值 `CHECK` 仍存在。
- 不恢复任何最终答案缓存；回答、流式回答、再生成和 API 引用都必须走同一可靠性决策边界。

### 计划 4：表格知识

- 表格导入必须成为现有资料生命周期中的格式提取/worker 能力，复用 staged → version → job → activation 链路；不得建立第二套并行资料版本系统。
- 源文件、结构化副本、只读 dataset SQLite、FTS 与向量状态必须与 `document_version_id` 一致，激活失败不得露出半完成版本。
- 公式永不执行；确定性网关只接收类型化查询计划，计算使用 `Decimal` 并区分 `0`、`False` 与 `None`。
- 对外提供表格问答前，至少完成计划 3 的证据类型、拒答和置信度边界。
- 计划 4 在部门、钉钉和 HR 权限模型延期期间只处理非敏感或合成资料；工资、考勤等敏感真实数据保持生产禁用。原计划中依赖 HR headers 的测试改为验证该禁用门禁，不得临时引入部门或 HR 数据访问能力。

### 企业治理与计划 5：客户话术

- 治理 Task 1–4 必须在话术发布前完成，尤其是权限版本、敏感分级和不可抵赖审计。现有 `material_audit_log` 不等同于追加式哈希审计链，不得直接冒充。
- 分类未确认时，资料不能进入 embedding、外部 LLM、索引或下载路径；这一门禁应置于现有 staging 与入队之间。
- 话术缓存必须使用独立 `speech:` 命名空间；命中时仍重查 ACL、权限版本与当前分类。固定话术路径不得调用模型。
- 话术评测夹具默认使用合成数据；任何真实数据进入前必须满足治理分级与脱敏审批。

### 计划 7–9：体验与助手

- 收藏、个人历史与通知只保存引用，不保存资料内容副本；展示或投递前重新检查 ACL、删除状态和当前版本。
- 助手平台的 DSL 必须是受界限的确定性 DAG。不要将旧 `RAGAgent` 直接扩展成平台；旧路径需要受功能开关和缩小权限约束。
- 计划 3 的 LlamaIndex 比较适配器只服务于窄的文档比较契约；助手 DSL 不应因此获得任意工具或数据库访问。
- 高级销售助手必须验证当前引用；数据分析助手只接收表格网关的 `StructuredQueryPlan`，不得执行 SQL、Python 或 Pandas。
